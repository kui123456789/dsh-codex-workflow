# DSH × Codex 本地可视化演示

这个独立页面演示「Codex 规划 → DSH 执行 → Codex 审查 → 修复或完成」的协作过程。它使用预设数据，不连接真实模型、Codex App Server 或 DSH，也不保存真实工作流。页面用于理解项目流程，并非正式 DSH 界面。

## 启动

在项目根目录运行：

```powershell
pnpm demo
```

浏览器打开 <http://127.0.0.1:4175/>。启动器只依赖 Node.js 内置模块，不需要构建项目，也不会更新 `lib/`。停止服务时，在启动终端按 `Ctrl+C`。

若默认端口被占用，选择其他端口：

```powershell
node demo/server.mjs --port 4176
```

然后打开 <http://127.0.0.1:4176/>。端口必须是 `1–65535` 的整数；服务只监听本机 `127.0.0.1`，不会自动结束占用端口的其他进程。

## 体验流程

- **标准流程**：观察规划、执行、审查到完成的完整过程。
- **审查修复**：观察审查发现问题、DSH 按意见修复，再次提交审查的循环。
- **原线程恢复**：观察工作中断后的暂停状态，再继续原线程，保留同一个线程标识。

使用页面上的自动播放、单步和重置控件控制演示节奏。原线程恢复场景会在中断处暂停，使用继续原线程的操作恢复后续步骤。切换场景或重置可重新体验。

所有状态、日志和线程标识都是浏览器内的模拟数据；刷新页面后重新开始。演示服务仅开放固定的 HTML、CSS 和 JavaScript 文件，不提供真实工作流操作 API。

## 目录与发布

- `index.html`、`styles.css`：页面结构与样式。
- `app.js`、`scenarios.js`：交互逻辑与预设场景。
- `server.mjs`：无外部依赖的本地静态服务，仅接受 `GET` 和 `HEAD`。

`demo/` 用于源码仓库内体验，不包含在插件发布包中。
